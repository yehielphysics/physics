# אתר "לומדים פיזיקה" — מדריך

אתר חינמי שמתארח ב-**GitHub Pages**, עם **פאנל ניהול** להוספת חומרים בלי קוד.
כל שינוי (דרך הפאנל או ב-GitHub) מתפרסם אוטומטית תוך 1–2 דקות.

---

## חלק א' — הקמה (פעם אחת, כ-20 דקות)

### 1. חשבון GitHub
נכנסים ל-github.com ← **Sign up**. חינם. כדאי לבחור שם משתמש קצר — הוא יהיה חלק מכתובת האתר.

### 2. יצירת מאגר
למעלה `+` ← **New repository**
- **Repository name:** `physics` (כתובת האתר תהיה `https://<שם-המשתמש>.github.io/physics/`)
- לסמן **Public** ← **Create repository**

### 3. העלאת הקבצים
1. פותחים (Extract) את קובץ ה-ZIP במחשב.
2. בדף המאגר לוחצים על הקישור **uploading an existing file**.
3. נכנסים לתיקייה שחולצה, מסמנים **את כל מה שבתוכה** (Ctrl+A) וגוררים לחלון.
4. מחכים שהכל יעלה ← **Commit changes**.

### 4. הפעלת האתר
1. במאגר: **Settings** ← בתפריט הצד **Pages**.
2. תחת **Source** בוחרים **GitHub Actions**.
3. עוברים ללשונית **Actions** למעלה. אמור לרוץ שם תהליך בשם *Deploy site*.
   - ✅ ירוק = האתר באוויר! הכתובת מופיעה ב-Settings ← Pages.
   - ❓ **אין שם כלום?** כנראה התיקייה הנסתרת `.github` לא עלתה (קורה במק). הפתרון:
     **Add file** ← **Create new file** ← בשם הקובץ כותבים בדיוק `.github/workflows/deploy.yml`
     ← מדביקים את התוכן של הקובץ `deploy.yml` (נמצא ב-ZIP בתוך `.github/workflows/`, או מבקשים מקלוד) ← **Commit changes**.

### 5. מפתח גישה לפאנל הניהול
הפאנל צריך "מפתח" כדי לשמור שינויים במאגר שלך:
1. ב-GitHub: תמונת הפרופיל ← **Settings** ← למטה **Developer settings** ← **Personal access tokens** ← **Fine-grained tokens** ← **Generate new token**.
2. **Token name:** `admin` · **Expiration:** 1 שנה.
3. **Repository access:** *Only select repositories* ← בוחרים `physics`.
4. **Permissions** ← **Repository permissions** ← **Contents** ← *Read and write*.
5. **Generate token** ← מעתיקים את המפתח (מוצג פעם אחת בלבד!) ושומרים במקום בטוח.

> 🔒 המפתח הוא כמו סיסמה — לא לשתף אותו ולא לשלוח לתלמידים.

## חלק ב' — הוספת חומרים

### דרך פאנל הניהול (מומלץ)
1. נכנסים ל-`https://<שם-המשתמש>.github.io/physics/admin/`
2. **Sign In Using Access Token** ← מדביקים את המפתח (פעם אחת בכל דפדפן).
3. **חומרי לימוד** ← **New** ← ממלאים: כותרת, נושא, סוג, מעלים קובץ ← **Save**.
4. אחרי 1–2 דקות החומר באתר.

**מזהה (Slug):** בצד הטופס יש שדה מזהה באנגלית — הוא יהיה כתובת הדף, למשל `momentum-worksheet-1`. לא לשנות אחרי הפרסום (קישורים ששלחת לתלמידים יישברו).

**נוסחאות** בשדה "תוכן נוסף": `$F=ma$` בתוך שורה, או בשורה נפרדת:
```
$$
E_k = \tfrac12 mv^2
$$
```

### דרך הפרויקט בקלוד
מביאים לפרויקט "אתר הפיזיקה שלי" קובץ מפרויקט אחר וכותבים *"תוסיף לאתר"*. קלוד יכין את הקובץ, יציע כותרת, נושא ותיאור, ויסביר מה להעלות.

### הוספת נושאים ורמות
בפאנל: **הגדרות האתר** ← **מבנה**. כדי להוסיף "אקדמיה": מוסיפים רמה (מזהה `university`) ← **Save** ← מחכים כ-2 דקות ומרעננים ← מוסיפים נושאים עם רמה = אקדמיה.
נושא חדש מופיע ברשימת הבחירה של החומרים (בשני האזורים) אחרי כ-2 דקות.
ברגע שיש יותר מרמה אחת, התפריט העליון עובר אוטומטית להציג רמות.

## חלק ג' — האזור הפרטי שלי (`/my/`)

מקום לחומרים **שרק אתה רואה**: מבחנים ופתרונות, מחוונים, קבצי Word לעריכה, טיוטות ופתקים.
הכל נשמר במאגר GitHub **פרטי** נפרד, לא מתפרסם באתר ולא מופיע בגוגל. נגיש מכל מחשב או טלפון.

### הקמה (פעם אחת, כ-5 דקות)
1. ב-GitHub: `+` ← **New repository**
   - **Repository name:** `physics-private` (בדיוק כך: שם המאגר הציבורי + `-private`)
   - לסמן **Private** 🔒
   - לסמן ✅ **Add a README file** (חשוב — מאגר ריק לא יעבוד)
   - **Create repository**
2. להוסיף את המאגר החדש למפתח הגישה שכבר יצרת:
   **Settings** ← **Developer settings** ← **Fine-grained tokens** ← לוחצים על `admin` ← **Edit**
   ← ב-*Repository access* מוסיפים גם את `physics-private` ← **Update**.
   (אותו מפתח משמש לשני האזורים.)

### שימוש
- נכנסים ל-`https://<שם-המשתמש>.github.io/physics/my/` (כדאי לשמור כסימנייה).
- **החומרים שלי:** כל פריט עם כותרת, נושא (אותם נושאים כמו באתר), כמה קבצים (למשל שאלון + פתרון), סטטוס והערות.
- **פתקים:** טקסט חופשי — רעיונות, תכנון שיעורים.
- **Assets** (בתפריט): כל הקבצים שהעלית, עם אפשרות להוריד.
- **סטטוס "מוכן לפרסום":** סימון לחומרים שתרצה להעביר לאתר. כדי לפרסם — יוצרים אותו בפאנל הציבורי (`/admin/`) ומעדכנים כאן ל"פורסם באתר".

### מגבלות שכדאי לדעת
- קובץ בודד עד כ-**25MB** (מספיק לכל PDF/Word/מצגת רגילה). סרטונים — עדיף ב-Google Drive או YouTube (לא-רשום) ולשמור כאן קישור.
- סך הכל עד כ-**1GB** במאגר. לארכיון גדול מאוד (סריקות, וידאו) Google Drive/OneDrive מתאימים יותר.
- הכתובת `/my/` עצמה גלויה, אבל בלי המפתח שלך אי אפשר לראות שום תוכן.

## חלק ד' — חשיפה בגוגל
1. נכנסים ל-[Google Search Console](https://search.google.com/search-console) ← **Add property** ← **URL prefix** ← כתובת האתר.
2. בוחרים אימות **HTML tag**, מעתיקים רק את הקוד שבתוך `content="..."`.
3. בפאנל הניהול ← **הגדרות האתר** ← **פרטי האתר** ← מדביקים ב"קוד אימות Google" ← Save. מחכים 2 דקות ← **Verify** בגוגל.
4. ב-Search Console ← **Sitemaps** ← מוסיפים `sitemap-index.xml`.

```
src/pages/admin/        ← פאנל הניהול הציבורי

```

- **סימון אדום ב-Actions** — לפתוח, להעתיק את הודעת השגיאה ולהדביק לקלוד.
